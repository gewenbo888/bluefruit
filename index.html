01

为什么是这四种类型

The Slate

选类型不看情怀，看比较优势：真人拍它贵在哪，AI 替它省在哪。
选片铁律：世界观驱动，回避强情绪特写——AI 的弱项，不进片单。

玄幻

Fantasy

法术、异兽、上古结界——靠后期一帧帧烧钱的画面，AI 直接生成。实景做不到的奇观，正是提示词的日常。

真人 ¥8–15万 / 集 → 蓝果 ¥0.5万 / 集

科幻

Sci-Fi

太空站、末世废土、赛博都市——美术置景预算的黑洞。搭不起的景，在生成模型里就是一句描述。

真人 ¥10–20万 / 集 → 蓝果 ¥0.6万 / 集

规则怪谈

Rule Horror

恐怖靠氛围，不靠脸。走廊、旧楼、贴满规则的墙——把日常场景怪谈化，正是生成模型的主场。

真人 ¥5–8万 / 集 → 蓝果 ¥0.4万 / 集

无限流

Loop / Instance

副本世界每集一换：雪国、孤岛、倒悬城市。真人剧换一个副本就是换一套置景组，蓝果换的是提示词。

真人 ¥8–12万 / 集 → 蓝果 ¥0.5万 / 集

03

制作管线

7 Days / Title

五道工序，一部 60 集的剧七天走完。人负责世界观与节奏，模型负责画面与量产。

STEP 1

剧本工坊

LLM · 世界观圣经

世界观设定一次写死，每集 90 秒一个钩子，第三秒必须出事。

2 天 / 部
STEP 2

分镜生成

文生图 · 风格锁定

每集 12–18 镜。角色一致性库钉死面孔与服装，画风全局锁定。

1 天 / 部
STEP 3

视频生成

首尾帧驱动 · 图生视频

分镜稿作首帧，模型补运动。远景与氛围镜头全自动，近景人工筛。

3 天 / 部
STEP 4

剪辑合成

自动粗剪 + 人工精剪

节奏卡点、字幕、音效自动套版，人工只掐情绪转折的帧。

1 天 / 部
STEP 5

上线分发

全平台 · 日更 2 集

完播率回流选品：哪类世界观涨得快，下一部就开哪个坑。
