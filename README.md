# 蓝果短剧 BlueFruit

原创科幻与幻想叙事，从分镜到成片。

## 网站功能

- 六集现有工程样片免费预览、选集、实际分辨率与时长展示、文稿阅读。
- 十二个原有故事设定保留在故事档案，明确标记为概念开发，不再声称已完成 465 集。
- 原有五类剧本与分镜资料支持选择、阅读与复制。
- 制作需求简报可以生成、复制、下载或由用户通过邮件发送。页面不会假装提交到不存在的后台。
- 原生对话框支持键盘关闭，手机端独立排版。

## 功能边界

现有视频为工程样片，主要展示分镜、文字、旁白与播放流程；不能代表影视级成片。首页背景为生成的概念视觉，并已标明。
移除了浏览器直接标记付款成功的解锁流程。当前全部样片免费，未接通订单与支付核验服务，不出售观看权益。
`gpu_fleet_orchestrator.py` 为任务规划样例，不作为真实运行 GPU 数量或制作成本证据。

## 中英文界面

顶部的中文 / EN 按钮切换界面与项目资料，选择保存在当前浏览器。可用 `?lang=en` 或 `?lang=zh` 分享指定语言。`i18n.js` 包含翻译词典与切换逻辑。用户输入与实验笔记保持原文；下载记录按当前语言生成。蓝果样片保留原中文音轨，并提供英文文稿。

## 可编辑交付工作台

工作台入口：/studio.html。原有公开内容与筛选保留。

- 项目简报、逐项任务/分镜、素材、验收、反馈、成果均可编辑并自动保存到当前浏览器 IndexedDB。
- 蓝果支持角色参考、镜头顺序、图片/视频素材版本、配音/音乐音轨，导出带字幕的视频、SRT 和制作文稿。优先使用浏览器支持的 MP4，否则 WebM。单次录制最长 180 秒，需保持前台；片段原声不会自动混入。
- AI for Money 支持任务完成记录、成果文件或 HTTPS 链接、验收及手动收支。金额由用户录入，未核验回款。
- 在 Money 导出蓝果制作简报，蓝果导入后制作，再把项目 ZIP 导回原 Money 项目。项目包包含素材、音轨和成果，支持恢复为副本。
- 归档和条目移除可恢复。任何实质编辑会把待验收/已交付状态退回制作中，避免继续显示过期验收状态。
- 中英文切换保留用户输入原文。没有云账号和跨设备自动同步；请定期备份。普通上传每个文件最多 25 MB，视频合成输出最多 80 MB，备份素材合计最多 120 MB。

### AI 服务配置

`api/generate.js` 是 Vercel Node 函数。复制 `.env.example` 中的变量到服务端；不要把密钥放进网页、连接文件或 Git。普通静态预览可编辑/导出，生成接口需要函数环境。

生成服务默认不启用。需要服务端配置提供商密钥、随机 `WORKSPACE_ACCESS_SECRET`、站点类型及精确 Origin。连接文件格式为 `{"sites":[{"url":"https://站点域名","accessToken":"对应的随机所有者口令"}]}`，文件仅交给所有者。导入后口令只在当前页面内存中使用，刷新后需重新连接；项目备份不包含口令。

文字方案先预览再加入，不覆盖已有工作。图片生成可通过 `WORKSPACE_IMAGE_ENABLED=false` 单独关闭。接口会报告配额失败，不会伪造成品。每个函数实例每小时最多 20 次请求；这不是跨实例的全局额度控制。没有生成服务时可手动编辑、上传、录制和导出。

### 工作台验证

`node --test tests/*.cjs`：验证未授权请求、跨站请求、服务未配置、配额错误、结构化方案、图片禁用及项目备份的素材/音轨恢复和 CRC 校验。
浏览器验收覆盖真实方案生成、三镜头带音轨 MP4 导出、字幕、制作包往返、刷新保存及手机布局。

Gemini 可通过 `GEMINI_API_KEYS` 配置 JSON 密钥数组。每次请求轮询起点，单次最多尝试两个可用密钥；401/403 冷却一小时，429/503 至少冷却一分钟并参考 Retry-After。冷却仅在当前函数实例内有效。同一 Google Cloud 项目的密钥共享项目配额，轮询不增加该项目额度。密钥不进入响应、网页或项目包。


## 平台入口与新手流程

蓝果首页优先观看。`/watch.html` 支持选集、下一集、自动连播、本浏览器观看进度和看单；`?film=demo` 播放实际制作的 6 秒创作示例。原有十二个故事设定保留，明确标记未成片。制作资料、提示词与咨询表单保留在 `/production.html`。

`/create.html`（蓝果）和 `/start.html`（Money）提供四步引导。蓝果完整示例自带三张画面、字幕与原创合成氛围音轨，无需生成服务即可编辑、录制和导出。高级编辑器与历史项目保留；引导模式和完整编辑器使用同一 IndexedDB。

Money 保留原有 24 个方向和全部组合筛选。品牌短片、小工具、研究简报三个入口帮助首次使用者开始。`在蓝果制作短片` 使用受来源、窗口和随机标记约束的 postMessage 交接简报；`交回 AI for Money` 将选定视频直接保存在原项目，按来源成果 ID 避免重复。接收方关闭后可继续使用原 ZIP 备份交接流程。不会自动勾选人工验收或记入收入。

## 账号、云端与投稿接入状态

云端依赖一个 Supabase Free 项目，可同时服务两个站点。仓库已准备迁移 `database/001-platform.sql`、邮箱登录客户端、私有 ZIP 存储、投稿和所有者审核 API；这些能力仅在真实服务接入并验证后开放。当前 `PLATFORM_LOGIN_READY` 默认 false，不把本机保存伪装成云端保存。

开通步骤：
1. 所有者在 Supabase 注册/登录并选择 Free 组织及免费项目；不绑定付费套餐。
2. 执行上述迁移，取得项目 URL、anon key 和服务端 service-role key。服务端密钥只保存到两个 Vercel 项目的环境变量；禁止写入仓库或页面。
3. 配置用户登录的实际邮件投递，以及两个正式域名的 `/account.html` 回调。Supabase 默认邮件投递受限；未验证真实登录前不能打开 `PLATFORM_LOGIN_READY`。
4. 使用两个测试账号核对项目与文件隔离、保存/恢复和投稿状态；所有者在蓝果 `/review.html` 审核。通过后只将成片复制到公开桶，私人项目包不公开。退回时填写具体修改意见，用户在 `/account.html` 查看。
5. 仅在这些检查完成后设置 `PLATFORM_LOGIN_READY=true`。账号可调用文字生成；服务端每日每账号最多 5 次、两个站点公共试用合计最多 100 次生成尝试。所有者保留原有独立连接方式。图片服务当前仍受提供商配额限制。

私有云端项目包和投稿文件各最多 50 MB，适应免费存储限制。本机项目包限制保持原值。登录状态保存在本浏览器，可退出；生成密钥不进入浏览器。免费项目的可用性、存储及流量上限以 Supabase 当前 Free 方案为准，不自动升级。

## 构建与校验

`npm run build` 仅把明确允许的网页和媒体复制到 `public/`。Vercel 打包根目录 API 与 `server/` 模块，服务端源文件不会作为静态资源发布。部署蓝果时从 Git 已提交版本重建六集样片，避免发布本地尚未提交的视频改动。

`npm test` 覆盖生成授权/配额、跨来源拒绝、云端身份绑定、投稿只能进入待审核、所有者审核限制，以及备份恢复和 CRC。云端集成测试仍须在免费服务开通后执行。

`/works.html` 统一列出本机草稿、归档入口、云端作品入口及账号/投稿进度。My work 的主入口不再直接进入高级编辑器。

GitHub login uses browser-bound PKCE and a ten-minute local verifier. Enable `PLATFORM_AUTH_GITHUB=true` only after configuring the dedicated OAuth app. `PLATFORM_AUTH_EMAIL` stays false until custom SMTP delivery is verified. Supabase default mail cannot provide public email sign-in. Server credentials are deployment environment variables, never public build files.
